# NovelStory 글꼴 묶음 (novelstory-fonts)

[NovelStory Studio](https://novelstory-studio.com) 에서 쓸 수 있는 공개 한글 글꼴을 **다운로드하기 쉽게 한곳에 묶어 놓은 저장소**입니다.
여러 배포처를 찾아다니지 않고, 아래 묶음 하나로 받아 바로 불러올 수 있습니다.

- 글꼴은 모두 각 저작권자가 **SIL Open Font License 1.1** 로 공개한 **원본 파일을 고치지 않고** 그대로 담았습니다.
- 글꼴마다 원본 라이선스(`OFL.txt`)와 저작권 표기(`COPYRIGHT.txt`)를 같은 폴더에 함께 두었습니다.
- 원본을 받은 주소와 SHA-256 은 [SOURCES.md](SOURCES.md) 에 있습니다.
- 이 저장소는 글꼴 저작권자와 관계없는 **비공식 묶음**입니다. 저작권자가 이 묶음을 만들거나 보증한 것이 아닙니다.

## 받기

- **묶음 한 번에 받기(ZIP)**: <https://github.com/HoneyOfOneDayButterfly/novelstory-fonts/archive/refs/heads/main.zip>
  - 또는 이 페이지의 초록색 「Code」 → 「Download ZIP」
- 글꼴 하나만 필요하면 아래 표의 폴더에서 파일을 받아도 됩니다.

## NovelStory Studio 에서 쓰기

1. 위 ZIP 을 받아 압축을 풉니다.
2. 앱의 「설정 → 전체 설정 → 사용자 글꼴」에서 「글꼴 불러오기」로 `fonts/<글꼴>/` 안의 `.ttf` 파일을 고릅니다.
3. 검사표를 보고 「추가하고 본문에 적용」 또는 「추가만 하기」를 고릅니다.
4. 원고 서식 도구줄의 글꼴 목록과 내보내기 창의 서체에 「· 사용자」로 나타납니다.

예전에 이 글꼴을 골라 둔 원고는 불러오기 전에는 같은 계열의 동봉 글꼴로 보이고, 불러오면 원래 글꼴로 보입니다.
다른 프로그램에서는 운영체제에 글꼴을 설치해 쓰면 됩니다.

## 라이선스

- **글꼴**: 각 글꼴 폴더의 `OFL.txt` 에 적힌 저작권자의 [SIL Open Font License 1.1](https://openfontlicense.org) 을 따릅니다.
  저장소 맨 위의 [LICENSE](LICENSE) 는 같은 OFL 1.1 전문입니다. 저작권과 예약 글꼴 이름은 글꼴마다 다르니 각 폴더의 `OFL.txt` 를 보세요.
- **이 저장소의 안내 글**(README.md · SOURCES.md): [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 으로 자유롭게 쓸 수 있습니다.

OFL 1.1 에서 지켜야 할 점은 다음과 같습니다(전문이 우선합니다).

- 개인·상업 용도 모두 쓸 수 있고, 문서·그림·책·웹사이트에 넣거나 소프트웨어와 함께 배포할 수 있습니다.
- 다시 배포할 때는 저작권 표기와 라이선스(`OFL.txt`)를 함께 넣어야 합니다.
- 글꼴 파일만 따로 **판매할 수는 없습니다**.
- 글꼴을 고친 판(수정판)은 예약 글꼴 이름(Nanum·MaruBuri·NanumBarunGothic·D2Coding·Plex·SUIT 등)을 쓸 수 없습니다.
  이 묶음은 원본 그대로라 이름을 바꾸지 않았습니다.
- 저작권자·제작자의 이름을 수정판의 홍보나 보증에 쓸 수 없습니다.

### English

A convenience bundle of open-source Korean fonts used with [NovelStory Studio](https://novelstory-studio.com), collected in one place for easy download.
Every font is an **unmodified original** released by its copyright holders under the **SIL Open Font License 1.1**; each font folder keeps its own
`OFL.txt` and copyright notice, and [SOURCES.md](SOURCES.md) lists the original download URLs, original license locations and SHA-256 hashes.
This is an unofficial bundle and is not endorsed by the copyright holders. Download everything as a ZIP: <https://github.com/HoneyOfOneDayButterfly/novelstory-fonts/archive/refs/heads/main.zip>
